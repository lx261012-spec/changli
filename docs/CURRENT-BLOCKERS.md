# 当前难点与设备限制

更新时间：2026-11-03。以下区分已经核对的技术要求、用户反馈和初步猜测。

## 1. 语音生成 Agent：声音克隆与实时生成

用户将语音生成 Agent 列为当前主要难点，希望使用 **Breeze-TTS 克隆声音**：

- 项目：https://github.com/breezeblue-ai/breeze-tts.git
- 本次核对的官方 README：https://github.com/breezeblue-ai/breeze-tts/blob/main/README.md
- 核对版本的 README blob：`3132361f8ae22ca728d29e06c7a5eb9afe241197`。
- 官方快速开始要求 Linux、Python 3.10 以上、支持 CUDA 的 NVIDIA GPU；推荐至少 12GB 显存运行 eager 路径。
- 用户反馈当前设备“没有显卡”，因此目前无法按官方 GPU 路线使用。这里准确记录为：**缺少该方案所需的兼容 CUDA 显卡，Breeze-TTS 当前设备上尚不可用，声音克隆和集成未完成。** 不将其扩大解释为本机没有任何图形显示硬件，也不承诺 CPU 或其他显卡能直接替代。

当前已有 GPT-SoVITS 的本地语音合成接口与角色语音素材；Breeze-TTS 是拟探索方案，不是现有成品已经使用的引擎。现有方案仍存在首次加载/合成延迟、角色表达与听感的验收问题，尚未满足整体低延迟目标。

待解决：获得符合要求的运行设备或另行评估可用部署路线，完成声音克隆、稳定运行、语音生成 Agent 的实际联动与端到端延迟测试。

## 2. 连接各种软件的智能性与稳定性

用户反馈：连接和操作各种软件时，智能性经常出问题，电脑响应跟不上。

**当前初步怀疑是设备配置偏低、运行负载过大，导致处理或交互延迟；这是待验证假设，尚未确定为根因。** 本次归档没有进行性能诊断，不把模型选择、连接配置、权限、GUI 动作执行、超时或应用适配问题排除掉。

现有代码中的固定 QQ 音乐启动与通用智能操作要区分：固定启动在本机验证过，但不能由此推断其他软件也已适配，或通用操作模型已正确配置。

后续定位应保留失败样本，并分别观察模型响应、工具调用、目标软件响应、CPU/内存/GPU/磁盘负载与执行超时，再判断硬件是否为主要瓶颈。目前没有低配设备与更高配置设备的同任务对照测试。
