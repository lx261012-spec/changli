# 长离聊天语音连接

本机测试台现在提供：底基保存新回复 → 调用长离 GPT-SoVITS → 播放独立 WAV。已存在的回复也可点击“播放 / 重试语音”。模型 API 未配置时，可以展开“输入文字试读”，输入文字后“合成并试听”，不需要聊天 API。

运行同目录“启动底基.cmd”，进入本机测试台。在“长离聊天语音”中选择“回复生成后自动播放语音”：开启时新回复保存后合成并播放，关闭时不自动合成/播放，仍可点击回复下方“播放 / 重试语音”或使用文字试读。关闭开关也会停止当前合成/播放。默认沿用开启，当前浏览器会持久保存选择，刷新或重新打开页面继续生效；首次使用兼容原会话中的勾选状态。保存受浏览器限制时会提示，本页选择仍有效。此偏好不跨浏览器同步，也不保存访问令牌。

“只停止语音”不打断聊天或电脑任务；发送新消息、切换角色/会话、退出本机连接会停止旧语音，迟到的旧结果不会再播放。浏览器禁止自动播放时，点击原生播放器播放键即可。

语音服务仅使用长离的首轮 v2 专属权重与通过的“此间当下.wav”推理参考，CPU FP32，语速 1.0，不做统一变速/变调。模型与参考文件启动时校验 SHA256，失败则提示，不换回其他音色。参考生成音不进入训练。爱弥斯没有配置音色时保持文字，不借用长离声音。原十五条场景语音、九条点触及其索引不改。

语音依赖沿用 `D:/GPT/背景项目/长离语音包/GPT-SoVITS试听` 的独立 Python 与本地模型；可在 `.env` 通过 `CHANGLI_VOICE_ROOT` 更改根目录。初始化配置写入底基自己的 `data/speech/tts_infer.yaml`，不覆盖试听 WebUI 的参数。推理进程首次调用时启动，成功后驻留；停止正在合成的请求会终止该进程，下次需要重新加载。无额外公网服务或端口，无收费 TTS。诊断失败保存在 `data/speech/last-error.log`。

## 接口（供显示模块使用）

- `GET /api/state?character=changli`：返回 `speech.configured`（文件配置可用）、`speech.ready` / `speechConnected`（当前进程已加载），不可把 configured 当作实际合成通过。
- `POST /api/characters/changli/speech`，JSON `{"text":"要朗读的回复"}`。仍需 `Authorization: Bearer <本机访问令牌>`，只接受本机同源。成功返回 `audio/wav`，响应头 `X-Audio-Seconds`、`X-Synthesis-Ms`、`X-Model-Load-Ms` 供诊断。失败返回已有结构的 JSON 错误；显示模块保留文字并提供重试。
- 取消 fetch 请求可停止合成；较新语音请求替换较旧合成。显示模块负责停止正在播放的 Audio，并丢弃旧请求的迟到结果。`public/speech-player.js` 已实现该规则，可沿用。
- 单次 1～2000 字符，不暗中截断；更长回复保留文字并提示分段试听。接口不把音频或访问令牌放入 URL，也不保存用户合成音频到语音包。

当前按完整回复合成后播放，**尚未实现边出字边说话，也未达到/验收首响应 6 秒与文音起始差 2 秒目标**。CPU 性能与首次模型加载时间见随交付的实测报告；接口可用不等于低延迟要求已达成。

底基真实模型密钥仍由用户在本机 `.env` 配置。不要把密钥发进聊天或角色设定。真实聊天模型未配置时，只能实测独立语音与使用明确标注的模型替身验证自动调用；不把替身测试写成真实模型聊天成功。

本轮只接通底基测试台的聊天语音能力。独立壁纸测试页仍维持已确认 revision5；其点触/聊天共用播放器、Electron主程序及真实系统壁纸由对应模块后续接入。按角色性格与场景细化主动建议仍待讨论。
